## [2026-08-27] 옵션 기능의 조용한 skip — 카카오 발송이 이틀간 무통보 중단

- **도메인**: `#secrets #observability #kakao`
- **요청**: "카톡이 안 온다" 원인 확인
- **증상**: 8/25 PC 포맷 후 카카오 발송만 중단. `daily`/`verify` 로그는 전부 `exit 0`, verify 는 PASS. 로그 어디에도 카카오 언급이 없어 언제부터 죽었는지조차 알 수 없었음.
- **원인**: 두 겹. ① 포맷 후 볼트를 재구성하며 `KAKAO_REST_API_KEY`·`KAKAO_TOKEN_PATH` 2개가 누락(텔레그램 키만 복원). ② `daily.ts` 의 카카오 분기가 `if (키 && 경로 && 파일)` 뿐이고 `else` 가 없어, 미설정이면 **로그 한 줄도 없이** 건너뜀. verify 도 카카오를 검사하지 않아 PASS.
- **수정**: 볼트에 키 2개 복원 + `npm run kakao:auth` 재인증(refresh token 은 포맷과 함께 소실 — 재발급만이 답). `daily.ts` 에 `else` 로 누락 항목을 명시하는 skip 로그 추가, `verify-daily.ts` 에 `kakao` 체크 추가(오늘 실행 구간에서 발송/경고/skip 흔적 검사).
- **규칙**: **best-effort 옵션 기능도 "안 했다"를 반드시 로그에 남긴다.** 조건부 실행 분기에 `else` 가 없으면 그 기능은 조용히 죽고 아무도 모른다. 자가검증(verify)에는 옵션 기능도 항목으로 넣되 미설정과 실패를 구분해 표시한다. 재설치·포맷 후에는 `.env.example` 의 키 목록과 실제 볼트 `.env` 를 **키 이름 기준으로 대조**해 누락을 확인한다(값은 출력하지 않는다).

## [2026-07-22] 스케줄 산출물 누락을 현재 시각 확인 없이 "실패"로 단정

- **도메인**: `#scheduler #diagnosis`
- **요청**: 브리핑 MD 생성이 언제부터 안 됐는지 확인
- **증상**: `files/`에 오늘(7/22) 산출물이 없는 것만 보고 "이틀째 실패"로 보고. 실제 현재 시각은 7/22 00:44로 06:00 스케줄 전이라 아직 실행될 차례가 아니었음. 진짜 실패는 7/21 하루뿐.
- **원인**: 산출물 유무만 보고 스케줄 시각 대비 현재 시각을 대조하지 않음. `tail logs/*.log` 출력이 비어 보인 것도 "로그 없음"으로 잘못 해석(실제로는 존재).
- **수정**: `TZ=Asia/Seoul date`로 현재 시각 확인 → 06:00 이전임을 확인 후 정정 보고. 로그는 파일별로 개별 `tail`.
- **규칙**: 스케줄 작업의 산출물 누락을 진단할 때 **먼저 `TZ=Asia/Seoul date`로 현재 시각을 확인**하고, 해당 날짜의 실행 예정 시각이 지났는지 판단한 뒤에만 "실패"로 분류한다. cron-run 로그는 `exit` 줄 유무로 정상종료/강제종료를 구분한다(`exit` 줄 없음 = 프로세스 강제 종료).

## [2026-07-22] .env append 시 마지막 개행 미확인으로 키가 기존 값에 붙음

- **도메인**: `#shell #env #secrets`
- **요청**: `.env`에 `KAKAO_TOKEN_PATH` 키 추가
- **증상**: `printf '...' >> .env` 후 새 키가 목록에 안 보임. 마지막 줄(`KAKAO_REST_API_KEY=<값>`)에 개행이 없어 값 뒤에 `KAKAO_TOKEN_PATH=...`가 이어 붙어 시크릿 값이 조용히 오염됨.
- **원인**: append 전에 파일 끝 개행 존재를 확인하지 않음.
- **수정**: 붙은 문자열을 sed로 제거 → `sed -i -e '$a\' .env`로 개행 보장 → 재append. 값 무결성은 `awk`로 키별 값 길이만 출력해 확인(값 비노출).
- **규칙**: 설정/시크릿 파일에 append하기 전 반드시 `sed -i -e '$a\' <file>`(또는 `tail -c1` 검사)로 마지막 개행을 보장한다. 검증은 값을 출력하지 말고 키 이름·값 길이만 확인한다.
